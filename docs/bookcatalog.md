# ТЗ: BookCatalog — Книжный каталог

## 1. Описание проекта

Веб-приложение для управления каталогом книг и авторов. Разработано в качестве тестового задания на Yii2 Advanced.

## 2. Цель

Создать полнофункциональный CRUD-интерфейс для книг и авторов с возможностью поиска, фильтрации и аутентификации пользователей.

## 3. Стек технологий

| Компонент | Версия / Название |
|-----------|-------------------|
| PHP | 8.2 |
| Фреймворк | Yii2 Advanced |
| База данных | PostgreSQL 15 |
| Веб-сервер | Nginx |
| Фронтенд | Yii2 Assets (Bootstrap 5) |
| Аутентификация | Yii2 User (email/пароль) |

## 4. Функциональные требования

### 4.1. Управление авторами (Author)
- Создание автора (имя, биография, дата рождения)
- Редактирование автора
- Просмотр списка авторов с пагинацией
- Просмотр карточки автора со списком его книг
- Удаление автора (с проверкой связей)

### 4.2. Управление книгами (Book)
- Создание книги (название, описание, год издания, ISBN, авторы)
- Редактирование книги
- Просмотр списка книг с пагинацией и поиском
- Просмотр карточки книги
- Удаление книги

### 4.3. Аутентификация
- Регистрация пользователя (email + пароль)
- Вход / Выход
- Восстановление пароля
- Подтверждение email

### 4.4. Поиск и фильтрация
- Поиск книг по названию
- Фильтрация по автору
- Поиск авторов по имени

### 4.5. Главная страница
- Отображение статистики (количество книг, авторов)
- Список последних добавленных книг

## 5. Нефункциональные требования

- Кеширование запросов к БД (getBooksCount)
- Адаптивная вёрстка (Bootstrap 5)
- Миграции для развёртывания структуры БД

## 6. Модели данных

### Author
| Поле | Тип | Описание |
|------|-----|----------|
| id | PK | Уникальный идентификатор |
| name | string | Имя автора |
| biography | text | Биография |
| birth_date | date | Дата рождения |
| created_at | datetime | Дата создания записи |
| updated_at | datetime | Дата обновления записи |

### Book
| Поле | Тип | Описание |
|------|-----|----------|
| id | PK | Уникальный идентификатор |
| title | string | Название книги |
| description | text | Описание |
| year | integer | Год издания |
| isbn | string | ISBN |
| created_at | datetime | Дата создания записи |
| updated_at | datetime | Дата обновления записи |

### BookAuthor (связь многие-ко-многим)
| Поле | Тип | Описание |
|------|-----|----------|
| book_id | FK | Ссылка на книгу |
| author_id | FK | Ссылка на автора |

## 7. API endpoints (Frontend)

| URL | Метод | Описание |
|-----|-------|----------|
| `/` | GET | Главная страница |
| `/book` | GET | Список книг |
| `/book/create` | GET/POST | Создание книги |
| `/book/update` | GET/POST | Редактирование книги |
| `/book/view` | GET | Просмотр книги |
| `/book/delete` | POST | Удаление книги |
| `/author` | GET | Список авторов |
| `/author/create` | GET/POST | Создание автора |
| `/author/update` | GET/POST | Редактирование автора |
| `/author/view` | GET | Просмотр автора |
| `/author/delete` | POST | Удаление автора |
| `/site/login` | GET/POST | Вход |
| `/site/signup` | GET/POST | Регистрация |

## 8. Деплой

- **Сервер**: Nginx + PHP-FPM
- **URL**: https://books.abxb.ru
- **База данных**: PostgreSQL 15
- **Миграции**: `php yii migrate`
